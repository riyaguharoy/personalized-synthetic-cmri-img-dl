Paper database

Every reference of the literature review: the generation studies with their input features, generator and evaluation metrics, and the datasets, methods and metrics the project builds on. The data sit in a SQLite file (papers.db) that your browser queries directly, so every filter below is a SQL query. Filter by group, search, sort, click a row for details, or write your own query at the bottom.

Read-only: only SELECT queries run, on the table papers. Columns:

Rows marked proposal were cited in the thesis proposal. The generation studies were compared one by one; the datasets, original method papers, techniques and metrics are listed with their bibliographic details only, and a dash means the column does not apply. “How it was read” says how much of each paper was opened. The datasets column is empty until it has been filled in from the papers; an empty cell means not recorded, not none. To add a reference, add it to tools/references.bib and run python tools/import_bib.py then python tools/build_db.py; the curated columns are edited in tools/papers.csv. The review is not exhaustive.
